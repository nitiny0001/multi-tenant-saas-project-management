# multi-tenant-saas-project-management
A multi-tenant SaaS project management platform built with FastAPI, React and PostgreSQL.


## Overview

This platform enables multiple organizations to manage their teams, projects, tasks, deadlines, and collaboration through a centralized application with secure tenant-level data isolation.

## Tech Stack

**Backend**
- Python
- FastAPI
- SQLAlchemy
- Pydantic
- PostgreSQL
- Alembic

**Frontend**
- React
- Vite
- JavaScript

**Tools**
- Git and GitHub
- Pytest
- Docker (planned)

## Core Features

- User authentication and authorization
- Organization and team management
- Role-based access control
- Project and task management
- Organization-level data isolation
- Notifications and activity tracking
- Dashboard and analytics
